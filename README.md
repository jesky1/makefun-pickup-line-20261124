One-line pickup line entry for make.fun's "The Perfect Pickup Line" bounty, $2 in USDC. The program writes a single pickup line an AI agent could actually say out loud — one line, at most 200 characters — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

